# translation-cards · 翻译卡片

一块**可拖动、可缩放**的悬浮翻译卡片：把文本粘进去（或直接打字），译文就地出现——不用在原文和翻译网站之间来回切窗口。

**单文件 · 零依赖 · 无需构建 · 无需 API Key** —— 双击 `assets/translation-card.html` 就能用。

> **v0.2.0 新增**：**实时翻译**（输入或粘贴后自动翻，不用点任何按钮）、**译法风格**（标准 / 专业 / 口语）、**渐变主题 + 确认按钮**（七套渐变预设、自定义两端色与角度）。

```
┌────────────────────────────────────────────┐
│ 翻译卡片 · 实时翻译                        │
│ 粘贴或输入文本，停顿后自动翻译             │
│                         Ctrl+Enter 立即翻译│
│ [标准 v] [中文 v]   [立即翻译]   [清空]    │
│ 译文显示在这里（可滚动、保留换行）         │
│                          拖右下角手柄缩放  │
└────────────────────────────────────────────┘
```

标题栏右侧三个按钮加一个状态圆点：**📌** 悬浮到最上层（盖住其他窗口）· **⚙** 主题与实时翻译设置 · **⌂** 重置位置与尺寸；圆点 ● 灰色=待输入、蓝色=请求中、绿色=已更新、红色=失败。按住标题栏可拖动整卡，拖右下角手柄可缩放。

## 1. 这个项目解决什么问题

读外文论文、说明书、代码文档、海外论坛时，最难受的不是看不懂，而是被打断：

- **切窗口的成本**：复制一段 → 切到翻译网站 → 粘贴 → 读译文 → 再切回来找下一段，一篇文章切几十次；
- **全页翻译插件的副作用**：把版式搞乱，还会顺手把代码块、行号一起翻掉；
- **桌面客户端的门槛**：要安装、要登录、要会员，为一个"看一段话"的需求太重。

translation-cards 换了个思路：**在屏幕上留一块属于你自己的小区域**。它浮在页面最上层（Chrome / Edge 下还能浮到浏览器之外，盖住 Word、PDF 阅读器、IDE），你把原文打进去或粘进去，**停手就自动出译文**——不用离开正在读的那一行，也不用再点一次按钮。

同一段话在不同场景要不同语气：论文里要**书面**，聊天里要**口语**；同一个卡片在不同时间要不同样子：白天浅色、夜里深色、想让桌面好看点就换成渐变。所以 v0.2.0 加了**译法风格**和**渐变主题**（配色改完点「确认」才生效，避免调色时来回闪）。

定位很明确：**对照阅读时的轻量翻译面板**。它不是全页翻译插件（不接管网页排版），也不是 CAT / 字幕工具（无术语库、无记忆库、无对齐编辑）。

## 2. 主要功能

| 功能 | 实际行为 |
|---|---|
| 悬浮卡片 | 页面内浮层，`position: fixed`；默认尺寸 460×360，初始位置距视口左上 80px；`z-index: 2147483647`（页面内最高层级） |
| 拖动 | 按住**标题栏**拖动整卡；位置被钳制在视口内，不会拖出屏幕找不回来 |
| 缩放 | 拖**右下角斜纹手柄**，最小 320×220，无上限 |
| **实时翻译** | 输入框里打字：停止输入 **0.7 秒**后自动翻译；粘贴：**0.12 秒**后自动翻译。全程不用点按钮 |
| 手动兜底 | 「立即翻译」按钮与 `Ctrl+Enter` 随时强制重译（跳过缓存） |
| 自动开关 | ⚙ 面板里的「实时翻译」复选框，关掉后只手动触发（状态记在 `localStorage['tc-auto']`） |
| **请求取消与去重** | 新输入会 `abort()` 上一次未完成的请求，并用自增序号丢弃过期响应；旧结果不会覆盖新结果 |
| **结果缓存** | 缓存「原文 + 语言对 + 接口原始译文」；同一段文本再触发不重复请求 |
| **译法风格** | 标准 / 专业（书面语域）/ 口语；切换风格**只重排已有译文，不重新请求接口**（秒切、不耗额度） |
| 多语言互译 | 目标语言 8 种：中文、英语、日语、韩语、法语、德语、西班牙语、俄语；**源语言自动检测** |
| 语言检测 | 按字符集启发式判断：假名 → 日语、谚文 → 韩语、西里尔字母 → 俄语、阿拉伯字母 → `ar`、汉字 → 中文、其余 → 英语。**先判假名再判汉字**，否则日语会被误判成中文 |
| **主题预设** | 浅色 / 深色 / 护眼绿 三套纯色方案 |
| **渐变主题** | 七套渐变预设：日出、海洋、薄荷、日落、紫罗兰、天空、石墨（深色）；另有自定义渐变（起始色 + 结束色 + 0–360° 角度） |
| **确认按钮** | 点色块、调颜色、改角度都只算「待确认」，卡片外观不变；点**「确认」**才生效并写入 `localStorage`，点**「还原」**放弃改动 |
| 渐变可读性 | 按两端颜色的平均亮度自动挑深色还是浅色文字/面板（`pickPalette`），浅渐变不糊字、深渐变不刺眼；卡片背景与页面背景同时变色 |
| 主题记忆 | 存 `localStorage['tc-theme']`，格式 `preset:light` 或 `gradient:#7dd3fc|#a78bfa|135|custom`；兼容 v0.1.0 的旧值（`light`/`dark`/`green`/裸色值） |
| 系统级悬浮 | 标题栏 📌 按钮通过 **Document Picture-in-Picture** 把卡片搬进独立顶层小窗，可盖住其他应用窗口；关窗后卡片自动搬回页面，译文与主题不丢 |
| 长文本分块 | 按句末标点切句后逐段请求再拼接：CJK 每块 ≤150 字符，拉丁文每块 ≤400 字符（接口单次约 500 字节上限） |
| 错误恢复 | 接口失败显示红色错误条 + 「重试」按钮，**原文保留不清空**，结果区显示「—」，状态圆点变红 |
| 边界处理 | 空输入提示、源/目标语言相同提示、纯符号/代码直接回显（不调接口） |
| 状态圆点 | 标题栏 ●：灰=待输入、蓝=请求中、绿=已更新、红=失败；请求超过 260ms 才显示「翻译中…」，避免短请求闪一下 |
| 快捷键 | 输入框内 `Ctrl+Enter` 立即翻译；`Esc` 收起设置面板 |
| 重置 ⌂ | 标题栏 ⌂ 按钮把卡片恢复为 80,80 / 460×360 |
| 清空 | 一键清空输入框、译文区与缓存 |

翻译引擎：**MyMemory 免费接口** —— `GET https://api.mymemory.translated.net/get?q=<文本>&langpair=<源>|<目标>`，支持 CORS、无需 API Key。

> **关于"实时"的边界**：v0.2.0 的实时是**防抖触发**——停止输入 0.7 秒（粘贴 0.12 秒）后自动发请求，**不是逐字符边打边译**。这样既做到"不用点按钮"，又不会每敲一个字母就打一次接口。短句通常 1 秒内出结果；长文本按块串行请求，耗时随块数线性增加。

## 3. 安装方法

### 3.1 直接用（推荐）

不需要安装任何东西，只要一个现代浏览器。

```bash
# 方式一：克隆
git clone https://github.com/Cr-02/translation-cards.git
# 方式二：在 GitHub 页面点 Code → Download ZIP，解压即可
```

然后双击 `assets/translation-card.html`，或用命令行打开：

```bash
# Windows (PowerShell)
Start-Process ".\assets\translation-card.html"
# macOS
open ./assets/translation-card.html
# Linux
xdg-open ./assets/translation-card.html
```

`file://` 直接打开即可，**不用起本地服务器、不用 npm install**。

### 3.2 作为 Agent Skill 安装

把整个目录放进 Agent 的 skills 目录（**目录名必须保持 `translation-cards`**，校验脚本会检查目录名与 `SKILL.md` 的 `name` 字段一致），然后对 Agent 说：

> 帮我打开翻译卡片

Agent 会读取 `SKILL.md`，把 `assets/translation-card.html` 复制到你指定的目录（未指定时是当前工作目录下的 `translation-cards/`），并用默认浏览器打开。

### 3.3 环境要求

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge **116+**（系统级悬浮窗需要 Document PiP）；Firefox / Safari 可正常使用，但只能做页面内浮层 |
| 网络 | 能访问 `api.mymemory.translated.net`（翻译请求发往该域名；界面本身离线可用） |
| 运行时 | 无。没有 npm、没有构建、没有后端、没有数据库 |
| 可选（校验） | Python 3.8+，跑 `quick_validate.py` |
| 可选（测试） | Node.js 18+，跑 `tests/` 里的单元测试 |

### 3.4 校验与测试

```bash
# 技能格式校验（SKILL.md / openai.yaml / README / HTML 结构 / tests 目录）
python quick_validate.py .

# 单元测试 + 结构冒烟测试
node --test tests/core.test.mjs tests/structure.test.mjs
```

- 格式校验会检查 `SKILL.md` frontmatter、`agents/openai.yaml`（含 `version` 是否为 `x.y.z`）、`README.md`、HTML 的关键结构标记、以及 `tests/` 两个测试文件是否存在；退出码 0 表示全部通过。
- **测试必须显式列出文件**：写成 `node --test tests/` 或 `node --test tests` 会被 Node 当作模块路径，报 `Cannot find module`，不是测试失败。
- 当前基线：**39 个断言全部通过**。

## 4. 使用方法

### 4.1 三步上手

1. 打开 `assets/translation-card.html`，屏幕左上出现一张卡片；
2. 复制任意外文文本，在卡片输入框里 **`Ctrl+V`** —— 松手就得译文；**直接打字也一样，停手 0.7 秒后自动翻译**；
3. 底部下拉框选**目标语言**与**风格**，点标题栏 **⚙** 换**主题**（选好后点「确认」）。

### 4.2 操作对照

| 操作 | 方式 |
|---|---|
| 移动卡片 | 按住标题栏拖动 |
| 调整大小 | 拖右下角斜纹手柄（最小 320×220） |
| 翻译 | 打字/粘贴后**自动**；或「立即翻译」按钮；或输入框内 `Ctrl+Enter` |
| 切换译法风格 | 底部左侧下拉：标准 / 专业 / 口语（立刻重排，不发请求） |
| 换目标语言 | 底部下拉（8 种，默认中文） |
| 换主题 | 点 **⚙** 展开面板 → 选纯色或渐变 → 点 **「确认」** |
| 自定义渐变 | ⚙ 面板里选起始色、结束色、角度（0–360，步进 15），点「确认」 |
| 放弃未确认的配色 | 点 **「还原」** |
| 关闭实时翻译 | ⚙ 面板取消勾选「实时翻译（粘贴或输入后自动翻译）」 |
| 进入系统级悬浮 | 点标题栏 **📌** |
| 退出悬浮 | 再点一次 📌，或直接关闭小窗（卡片自动归位） |
| 重置位置与尺寸 | 点标题栏 **⌂** |
| 清空输入与译文 | 点「清空」 |
| 收起设置面板 | `Esc` 或再点一次 ⚙ |

### 4.3 悬浮模式（盖住其他应用）

点标题栏的 **📌** 后，卡片被搬进一个 Document PiP 顶层窗口：

- 切到 Word / PDF / 其他网页，卡片依然在最上层；
- 小窗里继续打字/粘贴，**实时翻译、主题、输入内容、译文全部保留**（同一个 JS 上下文，事件监听不重建）；
- 关闭小窗 → 卡片自动搬回原页面，**已翻译的内容不会丢**。

兼容性：Chrome / Edge 116+。Firefox、Safari 不支持，点 📌 会提示换浏览器，此时页面内浮层照常可用。需要更强的"永久置顶"，可配合 Windows PowerToys 的 Always on Top（`Win+Ctrl+T`）。

### 4.4 主题与渐变（先选、后确认）

点标题栏 **⚙** 打开设置面板，自上而下四行：

1. **纯色**：浅色 / 深色 / 护眼绿；
2. **渐变**：日出、海洋、薄荷、日落、紫罗兰、天空、石墨（深色，适合暗色桌面）；
3. **自定义渐变**：起始色、结束色、角度（0–360，步进 15），旁边就是 **「确认」** 和 **「还原」**；
4. **实时翻译开关** + 「当前：…」状态文字。

规则很明确：

- 点色块或拖动取色器**不会立刻改变卡片**，只把面板状态改成「待确认：渐变 · 日落（#fa709a → #fee140，135°）」；
- 点 **「确认」** 才真正应用并写入 `localStorage['tc-theme']`，刷新后沿用；
- 点 **「还原」** 丢弃未确认的改动，回到上一次生效的配色；
- 渐变会同时作用在**卡片背景**与**页面背景**上，文字/边框/按钮颜色按两端颜色平均亮度自动选深或浅，避免"浅渐变配浅字"看不清；
- 旧版（v0.1.0）存下的 `light`/`dark`/`green` 或裸色值会自动换算成新格式，不会白屏。

### 4.5 译法风格（标准 / 专业 / 口语）

底部左侧下拉框：

| 选项 | 说明 |
|---|---|
| 标准 | 引擎原文，不做任何加工（默认） |
| 专业 | 书面语域：`立即→马上` 不会出现，反而 `现在→目前`、`没法→无法`、`don't→do not`、`so→therefore` |
| 口语 | 日常口语：`我们→咱们`、`已经→早已`、`do not→don't`、`therefore→so` |

要点：

- 切换风格**只对已有译文做本地重排**，不会再发一次请求——所以是秒切，也不消耗接口额度；
- 改**目标语言**才会重新请求；
- 规则表目前覆盖**中文、英文、日文、韩文**四种目标语言；法语/德语/西班牙语/俄语/阿拉伯语没有配规则，切换风格时译文保持原样；
- 这是**规则化语域替换**，不是让引擎按风格重译：命中规则才有差异，整句没命中时三档输出相同。

### 4.6 换成自己的翻译服务

翻译调用集中在 `assets/translation-card.html` 的 `translateChunk(text, from, to, signal)` 一个函数里，替换 URL 与参数即可接 DeepL / 百度 / 腾讯（`signal` 要透传给 `fetch`，否则实时翻译的取消机制会失效）：

```js
async function translateChunk(text, from, to, signal){
  const url = 'https://api.mymemory.translated.net/get?q='
    + encodeURIComponent(text) + '&langpair=' + encodeURIComponent(from + '|' + to);
  const res = await fetch(url, { signal });
  ...
  return t;   // 只要最终返回译文字符串
}
```

返回结构只需满足"从响应里取出译文字符串"。分块、防抖、取消、缓存、错误条、风格重排、主题这些逻辑都不用动。若目标语言编码与新服务不同，同时改 `#target` 的 `<option>` 值即可。

## 5. 输入输出示例

以下译文为 **2026-10-18 通过 MyMemory 接口实测**的结果，与卡片实际输出一致。机器翻译输出不保证长期稳定，同一输入在不同时间可能略有差异。

### 示例 1：英文技术文档 → 中文

**输入**（目标语言：中文，风格：标准）

```
The transformer architecture replaces recurrence with self-attention, enabling parallel computation over sequences.
```

**输出**

```
变压器架构用自注意力取代循环，实现对序列的并行计算。
```

> 术语提示：`transformer` 被通用引擎译成"变压器"。这是机器翻译的固有短板，代码里不做术语修正（修不好且会破坏通用性），专业场景请人工校对，或先做术语替换再粘贴。

### 示例 2：中文新闻 → 英文

**输入**（目标语言：英语）

```
国内生产总值同比增长百分之五点二，消费市场持续回暖。
```

**输出**

```
GDP grew by 5.2% year-on-year, and the consumer market continued to pick up.
```

### 示例 3：日文文学 → 中文

**输入**（目标语言：中文）

```
吾輩は猫である。名前はまだ無い。
```

**输出**

```
我是一只猫。我还没有名字。
```

日语正文含大量汉字，检测逻辑**先判假名**，所以这里不会被误判成中文而拒绝翻译。

### 示例 4：同一句、三种风格（v0.2.0）

**输入**（目标语言：中文）

```
Don't worry, it's good enough. We can do it right now.
```

| 风格 | 输出 |
|---|---|
| 标准 | `别担心，已经够好了。我们现在就可以做到。` |
| 专业 | `别担心，已经够好了。我们目前就可以做到。` |
| 口语 | `别担心，早已够好了。咱们现在就可以做到。` |

**输入**（目标语言：英语）

```
因此，我们必须立即降低这个项目的成本。
```

| 风格 | 输出 |
|---|---|
| 标准 / 专业 | `Therefore, we must immediately reduce the cost of this project.` |
| 口语 | `So, we must immediately reduce the cost of this project.` |

三档之间的差异来自本地规则表：命中规则就变，没命中就保持不变（所以上例的专业档与标准档相同）。

### 示例 5：实时翻译的触发行为

| 操作 | 实际发生的事 |
|---|---|
| 在输入框里逐字输入 `Hello world` | 每次输入都重置计时器，**停手 0.7 秒后**才发出请求；中间不会打 11 次接口 |
| `Ctrl+V` 粘贴一整段 | 0.12 秒后自动翻译 |
| 译文还没回来就继续改文本 | 旧请求被 `abort()`，旧结果被丢弃，只显示最后一次输入的结果 |
| 关掉 ⚙ 里的「实时翻译」 | 打字与粘贴都不再自动触发，只能点「立即翻译」或 `Ctrl+Enter` |

### 示例 6：长文本分块

## 7. 已知限制

- **实时 ≠ 逐字符**：触发时机是"停止输入 0.7 秒"或"粘贴 0.12 秒"，不是每敲一个字就译一次；状态圆点蓝色时表示请求还没回来。
- **译法风格是规则替换**：v0.2.0 的风格是在引擎译文上做语域改写，不是让模型按风格重译。规则表只覆盖中文/英文/日文/韩文，可能过度替换（例如把"处理"一律换成"弄"），也可能整句不命中而没有变化。
- **术语准确度**：通用引擎直译专业术语容易出错（`transformer` → 变压器、`architecture` → 建筑），属机器翻译固有局限，不在代码层修补。
- **自定义渐变要确认**：点色块、拖取色器都不会立刻生效，必须点「确认」；这是刻意设计，防止调色时来回闪。
- **位置与尺寸不持久化**：刷新后回到 80,80 / 460×360（主题会记住，几何不会）。
- **窗口层级**：仅 Chrome / Edge 116+ 能浮到浏览器之外；其他浏览器是页面内浮层，盖不住别的应用。
- **免费额度**：MyMemory 匿名使用有每日字符额度，超限会返回错误并显示错误条；可在 URL 上追加 `&de=your@email.com`（需自行改代码）提额，或换成自己的翻译服务。
- **隐私**：文本会发送到 `api.mymemory.translated.net`。v0.2.0 是**实时**翻译——**不点任何按钮**，停手 0.7 秒也会把输入框全文发出去。本项目没有自己的服务器、不做任何本地留存，但**不要粘贴密钥、个人身份信息等敏感内容**；担心误发可以先关掉「实时翻译」开关。
- **仅适配鼠标**：拖动与缩放监听 `mousedown` / `mousemove`，触屏设备体验未做适配。
- **语言检测是启发式**：极短句、混合语言（中英夹杂）可能判错源语言；阿拉伯字母会被识别为 `ar`，但目标语言下拉里没有阿拉伯语（要加需自行补 `<option>`）。
- **单文件取舍**：样式与逻辑内联在一个 HTML 里，方便分发；纯逻辑部分已抽到 `@core-begin`/`@core-end` 段并配有 Node 单元测试，但 DOM 交互仍靠 `structure.test.mjs` 做结构冒烟检查，没有浏览器端 E2E。

## 8. 常见问题

| 问题 | 原因与处理 |
|---|---|
| 输入或粘贴后没反应 | 先看 ⚙ 面板里的「实时翻译」是否被取消勾选；再确认文本不是纯符号/数字（纯符号会直接回显）；圆点变红说明请求失败，看下方错误条 |
| 改了颜色但卡片没变 | 配色是「先选后确认」：点完色块或拖完取色器还要点 **「确认」**；想放弃就点「还原」 |
| 切换风格后译文没变化 | 该目标语言没配规则（法/德/西/俄/阿），或这句话没有命中任何规则——规则替换只改措辞，不会重译 |
| 译文短暂显示"翻译中…"后才出来 | 请求超过 260ms 才会显示这个提示，短请求直接出结果，属于正常表现 |
| 双击打开是空白 / 无样式 | 确认文件完整（728 行、约 31KB）；`file://` 打开本身是被支持的 |
| 点「立即翻译」没反应 | 浏览器未授权读剪贴板时该调用会挂起，卡片 400ms 后跳过读剪贴板、直接翻译输入框内容——先在输入框里手动 `Ctrl+V` 再点按钮即可 |
| 译文出现"变压器""建筑" | 机器翻译把 `transformer` / `architecture` 按日常义直译，属已知局限，请人工校对 |
| 点 📌 提示不支持悬浮窗 | 当前浏览器不是 Chrome / Edge 116+；换浏览器，或继续用页面内浮层 |
| 提示"翻译失败：HTTP 4xx" | 多为免费额度用尽或频率限制，可稍后重试或换接口（见 4.6） |
| 刷新后卡片位置变了 | 设计如此：几何状态不持久化，点 ⌂ 可随时复位 |
